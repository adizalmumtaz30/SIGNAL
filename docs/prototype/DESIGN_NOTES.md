# Catatan desain SIGNAL

- Arah visual: sekolah kontemporer, bukan masjid; cream/ivory, forest green, sage, dan brass terbatas.
- Layout: hierarki dashboard tradisional dengan kolom konten dan panel samping; tidak memakai Bento grid sebagai bahasa komposisi utama.
- Surface: garis tipis, radius terukur, bayangan halus; tidak memakai glassmorphism, bevel, atau skeuomorphism.
- Ilustrasi dibuat sebagai aset SVG lokal dan digunakan ulang pada beberapa area inti untuk menjaga identitas serta menghindari dependensi gambar eksternal.
- Prioritas: hemat dependensi, bisa dijalankan secara lokal, mudah dirawat, tetap terbaca pada ukuran desktop dan mobile.
