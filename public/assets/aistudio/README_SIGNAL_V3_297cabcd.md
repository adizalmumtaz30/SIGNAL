# SIGNAL V3 — Expressive Jewel Luxury Design Handoff

Paket ini berisi spesifikasi visual/UX, atlas mockup bernomor, prototype HTML, prompt eksekusi AI Studio, dan metode riset desain.

## File utama
- `design.md` — spesifikasi lengkap dan redesign detail tiap core/fitur.
- `SIGNAL_V3_Mockup_Atlas.html` — prototype preview 24 plate. Buka file ini di browser.
- `PROMPT_GOOGLE_AI_STUDIO_SIGNAL_V3.md` — prompt utama untuk implementasi di repo.
- `RESEARCH_METHODS.md` — metode premium digital, visual hierarchy, plain language, accessibility, dan cara pengujian.

## Cara membaca Atlas
HANYA Plate 01 merupakan Beranda. Plate 02–22 adalah layar/tab/dialog/alur fitur yang berbeda. Plate 23 adalah referensi komponen; Plate 24 adalah responsive reference. Atlas bukan sitemap produksi dan tidak boleh dijadikan satu homepage.

## Batasan prototype
File HTML adalah demonstrasi visual/interaksi lokal. Data yang terlihat adalah data contoh. Tidak terhubung ke repository SIGNAL, IndexedDB, generator, validator, publish, PDF export, atau backup production. Implementasi production harus memakai handler, schema, dan service existing.

## Arah desain
`EXPRESSIVE JEWEL LUXURY — THE GRAND ACADEMIC ATELIER` memakai emerald, jade, midnight blue, plum, warm ivory, dan antique gold dengan Fraunces × Inter. Ini bukan quiet luxury dan bukan dashboard SaaS generik. Kekayaan visual harus hadir di seluruh core tanpa mengganggu keterbacaan, kecepatan, dan kesederhanaan.
